# Roadmap

1. **Skeleton** (done): target hash, build generator, objdiff config, docs, CI.
2. **Analysis baseline** (done): scripted Ghidra analysis and delinking, region map in [regions.md](regions.md), first target object (zlib `adler32`) delinked and loaded in objdiff.
3. **First matching unit** (done): zlib 1.2.2 `adler32.c` compiled with cl 13.10.3077 `/O1` matches 100% in objdiff, proving the delink → compile → diff loop.
4. **Libraries** (in progress): build ODE, zlib, libjpeg 6b and libpng from upstream source with matching flags, and mark those units complete. FreeImage's zlib 1.2.2 (8 units), libpng 1.2.8 (14) and libjpeg 6b (37) are done at 100%, and so are FreeImage 3.7.0's own C++ code (21 units, 0x559e00–0x56717b) and ODE 0.5 with OPCODE (49 units, 0x586fd0–0x5bda8f). The libpng 1.0.5 and zlib copies in block 1 belong to the prebuilt D3DX8 library and are linked from `d3dx8.lib`.
5. **Progress reporting** (done): `tools/report.py` reports progress over all of `.text`, the measured report, a progress page and the badge data are committed in `progress/`. A decomp.dev listing is a sign-in away; see [maintainers.md](maintainers.md).
6. **Engine and game code** (started): decompile Tongas2 and game units. Matched so far, all 100%: `APPOPTIONS` (display and sound settings in optionswtj.dat, 10 functions), `SRESULT` (script result values, 19 functions), `SYSMONITOR` (heap and CPU usage sampling, 5 functions), `TOKENS` (the script tokenizer, 7 functions), `FILELOADER` (plain file reading, 15 functions), `FILELOADERWKZ` (reads `name.wkz` instead when it exists, 15 functions) and `WKZ` (the zlib-compressed .wkz format, 6 functions). `RESOURCES` (the resource system: its 26 type managers, the master and copy indexes, groups, channels and volume settings, 93 functions) also matches 100% of its code. `RESOURCE` (the base classes of what the resource system holds: `RESOURCEMASTER`, which hands out copies of a loaded resource, `RESOURCE`, one copy, and `OBJECT`'s placement code, which follows a parent actor or a tag and works out where to draw the object) matches 35 of its 36 functions; `RESOURCEMASTER::TrimCopies` is still off. `MATHS` (the `V3` vector helpers: box and segment tests, Catmull-Rom splines, triangle normals and headings) is in with 4 of its 6 functions at 100%; the two spline functions are each a couple of instructions off. WildTangent's leaderboard SDK, which the game links in, is also matched: `WTLEADERBOARD` (4 functions), `WTLEADERBOARDIMPL` (builds the submit and view URLs, 3 functions plus a static string) and `WTCRYPT` (the score obfuscation, 3 functions).
7. **Full link**: link all objects with link 7.10.3077 and reproduce `Tornado.exe` byte-for-byte.
