# readable strings, flag-table copies or code. They are present in Tornado.exe

# complete while its data is below 100%.

# Ranges are inclusive virtual addresses. For code patches the range is the
# opaque byte run; the containing function/instruction starts at the address
# the finder reported (often one or two bytes earlier).
#
# A readable suffix next to a patch is evidence for the original string; use
# the suffix, not the opaque bytes, when writing source.
