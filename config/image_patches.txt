# Image-integrity exceptions in the committed Tornado.exe (SHA-1 20bf7200...).
#
# A handful of 15-19 byte opaque blocks in the image overwrite otherwise
# readable strings, flag-table copies or code. They are present in Tornado.exe
# itself, not produced by the delinker, so genuine C++ source cannot reproduce
# them. The affected data items and units stay partial: never mark a unit
# complete while its data is below 100%.
#
# Format: <start>-<end>  <unit>  <what the block covers>
# Ranges are inclusive virtual addresses.
#
# A readable suffix next to a patch is evidence for the original string; use
# the suffix, not the opaque bytes, when writing source.
